# Тестовое задание: Python + Django

## Цель

Написать сервис, который интегрируется с внешними учётными системами. Реализовать одну интеграцию и предусмотреть относительно несложное добавление интеграций из других внешних систем.

---

## Внешняя система: 1С

### Пример запроса на получение списка сотрудников

- **Метод:** POST  
- **URL:** `http://176.192.70.122:90/fitnes_t_nfc_mobile/hs/nfc_mobile/v1`  
- **Auth:** Basic  
  - login: `FitnessKit`  
  - password: `vY0xodyg`  

**Тело запроса (Body):**

```json
{
  "Request_id": "e1477272-88d1-4acc-8e03-7008cdedc81e",
  "ClubId": "59115d1e-9052-11eb-810c-6eae8b56243b",
  "Method": "GetSpecialistList",
  "Parameters": {
    "ServiceId": ""
  }
}
```

- `Request_id` — хардкодится для данного метода (`Method`).
- `ClubId` — изменяемый параметр (разный для разных копий учётной системы).

**Настраиваемые параметры:** ClubId, login, password, URL (ссылка на 1С).

---

## Требуемый функционал

### API

Реализовать запрос:

**GET** `/team/get_employees`

- Получает данные из внешней системы (1С).
- Преобразует их и отдаёт в ответ.

### Формат ответа

Не обязательно реализовывать все поля. В ответе у сотрудников обязательно должны быть:

| Поле       | Описание                    |
|-----------|-----------------------------|
| `id`      | Идентификатор сотрудника    |
| `name`    | Имя сотрудника              |
| `last_name` | Фамилия сотрудника        |
| `phone`   | Телефон сотрудника          |
| `image_url` | Аватар сотрудника         |

При отсутствии поля — отдавать пустую строку `""`.
